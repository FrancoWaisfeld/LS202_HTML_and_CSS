# Launch School Course LS202 HTML and CSS

This repository contains practice exercises from Launch School's LS202 course.

## What I learned in this course:

### Foundational Concepts

- HTML basics: Structuring HTML documents with elements like headers, paragraphs, and links.
- Classes, IDs, and Names: Applying styles and uniquely identifying elements within HTML.

### Styling with CSS

- Adding Style: Applying styles to web pages, including text formatting and CSS selectors.
- Box Model: Understanding how elements are treated as boxes, including padding, margins, and box sizing.
- Visual Formatting: Learning how elements are visually formatted on a page.

### Working with Media and Layouts

- Images: Exploring different image types and methods to incorporate them into web pages.
- Lists and Tables: Creating and styling lists and tables.
- Forms: Understanding form elements, input types, and attributes for creating interactive forms.

### Advanced Layout Techniques

- Floats and Positioning: Using floats and positioning to layout elements.
- Flex and Grid: Employing modern layout techniques using Flexbox and CSS Grid for responsive design.
- Responsive Design: Making web pages responsive using media queries and CSS frameworks.
